# Visual direction

Build target: the supplied Gremlin brief, translated directly into an evidence report. No generated product imagery; all finding images are real browser screenshots.

| Decision                                      | Source                                   | Role                           | Why                                                         |
| --------------------------------------------- | ---------------------------------------- | ------------------------------ | ----------------------------------------------------------- |
| Near-black canvas, off-white copy             | User brief                               | Main report surface            | Keeps the terminal identity coherent                        |
| Acid green                                    | User brief                               | Brand, score, links, focus     | One memorable accent; reserved red/amber for severity       |
| Sans headings + system monospace              | refero-design typography craft reference | Hierarchy / technical evidence | Scan findings quickly; read URLs and selectors precisely    |
| Thin borders, 3px corners, no glow            | User brief                               | Separation                     | Dense engineering evidence without a generic SaaS dashboard |
| Score + evaluated denominator above findings  | Product brief                            | First assessment               | Makes scope visible before users infer quality              |
| Open reproduction details and screenshot link | Product brief                            | Evidence                       | Finding utility before personality                          |
| Responsive single column at 700px             | refero-design craft + brief              | Mobile report reading          | Prevent the report itself from becoming a UX bug            |

Design research used the locally installed refero-design craft references (typography, color, visual workflow); live Refero tools were unavailable. No claim that external design screens were reviewed.

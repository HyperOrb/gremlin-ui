Name: Gremlin
Tagline: Find the UX bugs you didn't know to test for.

Description: Local-first UX chaos testing for web apps. Gremlin launches Chromium, tries five families of unexpected interactions, and produces screenshots and reproduction steps in a static report. TypeScript, Playwright, MIT. No API keys or signup.

Maker comment draft: Happy-path tests are valuable, but they use an app exactly as expected. Gremlin challenges those assumptions. The demo is an actual broken/fixed app, and the coding-agent skill adds an evidence-first repair loop. This is an early release with documented heuristics and safety limits; I'd love concrete failing fixtures and false-positive reports.

Do not claim the tool proves perfect UX or backend idempotency. Attach only generated real-run media. Add public links only after launch.

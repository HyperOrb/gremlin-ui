You can't write a test for a bug you never imagined.

I'm building Gremlin, a local UX chaos tester for web apps. It challenges the assumptions behind happy-path tests with tiny screens, invalid inputs, keyboard navigation, history and repeated clicks.

The output is evidence you can act on: screenshots, selectors, reproduction steps and JSON. It runs without a model or cloud key. The demo shows the same real app before and after fixes.

Early v0.1; feedback on false positives is welcome. [Add repository link when public.]
